SYNTHETIC FIXTURE / 合成示例

用能手算的价格，核对成本与持仓

人为设定价格为 100 → 110 → 99，首期建仓收取 10 bps 成本；第二期持仓不变，期末不强制清仓。

初始资产       1.00000
首期建仓后     1 × 0.999
两期净期末资产  0.999 × 1.1 × 0.9 = 0.98901
基准期末资产    1.01000

运行脚本后，可检查两期持仓明细、毛净收益、换手与输入缓存哈希。测试会核对数值并检查是否改写输入。

这些数字是程序核算样本，不是真实行情回测或实盘业绩。实际披露时点、复权分红和可成交约束仍需进一步建模。

03 / REPRODUCE

在本地复现这两个合成示例

需要 Python 3.11+。安装依赖后，演示读取仓库内的 CSV，不访问市场数据服务。

git clone https://github.com/Serennity007/awesome-stock-quant-skills.git
cd awesome-stock-quant-skills
python -m pip install -r requirements-demo.txt
python scripts/run_demo.py

完成后打开 output/demo/run-…/REPORT.md。报告连接到共识 CSV、回测持仓、输入哈希与日志；重复运行创建新目录，保留已有结果。
