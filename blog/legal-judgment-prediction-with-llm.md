# 用 LLM 做法律判决预测：知识-经验双轨融合方法

*2026-07-15 · 研究*

## 背景

法律判决预测是法律 AI 领域的核心任务。传统方法依赖于特征工程和浅层模型，难以捕捉法律推理的深层逻辑。

我们提出了一种基于大语言模型的知识-经验双轨融合框架，将法律条文知识和司法先例经验结合起来，提升判决预测的准确性和可解释性。

## 方法

### 整体架构

```
案件事实 → 7B LLM → 犯罪要素提取
                        ↓
              ┌─────────┴─────────┐
              ↓                   ↓
        Milvus 向量库         法律条文库
        (司法先例检索)        (知识匹配)
              ↓                   ↓
              └─────────┬─────────┘
                        ↓
        原始案情 + 知识 + 先例 → 30B LLM → 判决预测
```

### 关键创新

1. **双轨检索**：同时检索法律知识和司法先例，提供多维度参考
2. **要素提取**：用小型 LLM 提取犯罪构成要素，降低大模型的输入噪声
3. **融合推理**：将多源信息融合后输入大模型，生成综合判决预测

## 实验

### 数据集

- 来源：中国裁判文书网公开数据
- 规模：10,000+ 刑事案件
- 任务：罪名预测、刑期预测、法条推荐

### 结果

| 方法 | 罪名准确率 | 刑期 MAE |
|------|-----------|----------|
| 基线 BERT | 78.3% | 8.2 月 |
| GPT-4 直接推理 | 82.1% | 6.5 月 |
| **我们的方法** | **87.6%** | **4.8 月** |

### 消融实验

| 组件 | 罪名准确率 |
|------|-----------|
| 仅知识引导 | 83.2% |
| 仅先例引导 | 84.7% |
| 双轨融合 | 87.6% |

双轨融合比单一引导提升 3-4 个百分点。

## 可解释性

我们的方法不仅给出预测结果，还能展示推理过程：

```
案件：盗窃案，涉案金额 5000 元

要素提取：
- 行为：秘密窃取
- 对象：他人财物
- 金额：5000 元（数额较大）

匹配法条：
- 《刑法》第264条：盗窃罪
- 数额较大：1000-10000 元

参考先例：
- (2023)粤01刑终123号：类似案情，判处有期徒刑6个月

预测：盗窃罪，有期徒刑6-8个月
```

## 局限性

1. 数据偏差：公开裁判文书可能存在选择偏差
2. 地域差异：不同地区的量刑标准可能不同
3. 伦理风险：AI 辅助判决需要严格的伦理审查

## 结论

知识-经验双轨融合框架在法律判决预测任务上取得了显著提升。未来工作将探索更多法律领域的应用，并加强可解释性和公平性研究。
